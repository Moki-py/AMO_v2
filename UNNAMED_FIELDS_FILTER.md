# Фильтрация безымянных полей в интерфейсе экспорта

## ✅ Новая функция добавлена

В интерфейс настроек экспорта добавлена возможность скрытия технических полей без понятных названий.

## 🎯 Проблема

В интерфейсе отображались поля с техническими названиями:
- `custom_field_2010696`
- `custom_field_2010697`
- `Custom Field 123456`

Это засоряло интерфейс и затрудняло выбор нужных полей.

## 🔧 Решение

### 1. Новый переключатель "Технические поля"

В панели "Доступные поля" добавлен чекбокс **"Технические поля"**:

- ☐ **Выключен (по умолчанию):** Показываются только поля с понятными названиями
- ☑ **Включен:** Показываются все поля, включая технические

### 2. Визуальная индикация

Технические поля помечаются оранжевым бейджем **"ID"** в правом верхнем углу.

### 3. Умная фильтрация

Система автоматически определяет технические поля по критериям:

**Техническими считаются поля:**
- Начинающиеся с `custom_field_` и содержащие только цифры
- С названием "Custom Field [ID]" (fallback имя)
- Без `field_name` из AmoCRM HAL данных

**Дружелюбными считаются поля:**
- С именами из `field_name` AmoCRM
- Стандартные поля системы
- Поля с осмысленными названиями

## 🚀 Как использовать

### По умолчанию (рекомендуется)
1. Чекбокс **"Технические поля"** выключен
2. Видны только поля с понятными названиями:
   - ✅ "Источник (Маркер)"
   - ✅ "Бюджет клиента"
   - ✅ "Тип услуги"

### Показать все поля
1. Включите чекбокс **"Технические поля"**
2. Увидите дополнительные поля с бейджем "ID":
   - 🔶 `custom_field_123456` **ID**
   - 🔶 `custom_field_789012` **ID**

### API параметр

Программно управлять фильтрацией можно через API:

```javascript
// Только дружелюбные поля (по умолчанию)
GET /api/export-settings/fields/deals

// Все поля, включая технические
GET /api/export-settings/fields/deals?include_unnamed_fields=true
```

### Визуальные индикаторы
- **Дружелюбные поля:** Обычное оформление
- **Технические поля:** Оранжевый бейдж "ID" в углу
- **Кастомные поля:** Синий бейдж "Custom"
