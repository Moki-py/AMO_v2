# Система настроек экспорта данных AmoCRM

## Обзор

Новая система настроек экспорта данных предоставляет мощный и интуитивный интерфейс для настройки экспорта данных из AmoCRM. Система включает в себя современный веб-интерфейс с поддержкой drag-and-drop, предпросмотром данных и сохранением настроек.

## Основные возможности

### 1. Динамическая загрузка полей
- Автоматическое обнаружение всех доступных полей из базы данных
- Поддержка вложенных объектов и массивов
- Определение типов полей (текст, число, дата, email, URL и др.)
- Обработка кастомных полей AmoCRM

### 2. Интерактивный интерфейс
- Вкладки для переключения между типами сущностей (сделки, контакты, компании, события)
- Поиск по полям в реальном времени
- Drag-and-drop для выбора и изменения порядка полей
- Анимации и плавные переходы

### 3. Предпросмотр данных
- Живой предпросмотр выбранных полей
- Примеры реальных данных для каждого поля
- Табличное представление результата экспорта

### 4. Сохранение настроек
- Сохранение конфигураций экспорта в MongoDB
- Загрузка сохраненных настроек
- Управление множественными конфигурациями

## Архитектура

### Backend (FastAPI + MongoDB)
```
export_settings.py - Основной модуль управления настройками
├── ExportSettingsManager - Главный класс для работы с настройками
├── FieldInfo - Информация о поле для экспорта
├── ExportSettings - Настройки экспорта для конкретного типа сущности
└── EntityType - Перечисление поддерживаемых типов сущностей
```

### API Endpoints
```
GET /api/export-settings/fields/{entity_type} - Получить доступные поля
GET /api/export-settings/preview/{entity_type}/{field_name} - Предпросмотр поля
POST /api/export-settings - Сохранить настройки
GET /api/export-settings - Список сохраненных настроек
GET /api/export-settings/{settings_id} - Получить настройки по ID
PUT /api/export-settings/{settings_id} - Обновить настройки
DELETE /api/export-settings/{settings_id} - Удалить настройки
POST /api/export-settings/clear-cache - Очистить кэш
```

### Frontend (HTML + JavaScript)
- Современный адаптивный интерфейс
- Асинхронная загрузка данных
- Кэширование на стороне клиента
- Обработка ошибок и уведомления

## Использование

### 1. Доступ к интерфейсу
Перейдите на страницу настроек экспорта:
```
http://localhost:8000/export-settings
```

### 2. Выбор типа сущности
Используйте вкладки в верхней части страницы для переключения между:
- Сделки (Deals)
- Контакты (Contacts)
- Компании (Companies)
- События (Events)

### 3. Выбор полей
- **Поиск**: Используйте поле поиска для быстрого нахождения нужных полей
- **Клик**: Кликните на поле в левой панели для добавления в выбранные
- **Drag & Drop**: Перетащите поле из левой панели в центральную

### 4. Настройка порядка
- Перетаскивайте поля в центральной панели для изменения порядка
- Используйте кнопку "×" для удаления поля из выбранных

### 5. Предпросмотр
- Правая панель автоматически показывает предпросмотр выбранных данных
- Отображаются реальные примеры из базы данных

### 6. Сохранение настроек
1. Введите название настройки
2. Добавьте описание (опционально)
3. Нажмите "Сохранить настройки"

### 7. Загрузка настроек
- Нажмите "Загрузить настройки" для просмотра сохраненных конфигураций
- Выберите нужную конфигурацию для применения

## Технические особенности

### Кэширование
- Поля кэшируются на 15 минут для оптимизации производительности
- Предпросмотр данных кэшируется отдельно
- Принудительное обновление через кнопку "Обновить"

### Обработка кастомных полей
- Автоматическое определение кастомных полей по паттернам
- Извлечение ID кастомных полей
- Специальная маркировка в интерфейсе

### Типизация полей
Система автоматически определяет типы полей:
- `text` - Текстовые поля
- `number` - Числовые значения
- `date` - Даты
- `email` - Email адреса
- `url` - URL ссылки
- `boolean` - Логические значения
- `array` - Массивы
- `object` - Объекты

### Безопасность
- Валидация всех входных данных
- Обработка ошибок на всех уровнях
- Безопасное хранение в MongoDB

## Интеграция

### С существующими экспортерами
Система интегрируется с:
- Excel экспортером
- Google Sheets экспортером
- Параллельным экспортером

### Расширение функциональности
Для добавления новых типов сущностей:
1. Добавьте новый тип в `EntityType`
2. Обновите маппинг коллекций в `entity_collections`
3. Добавьте соответствующую вкладку в интерфейс

## Устранение неполадок

### Частые проблемы
1. **Поля не загружаются**: Проверьте подключение к MongoDB
2. **Предпросмотр пустой**: Убедитесь, что в коллекции есть данные
3. **Настройки не сохраняются**: Проверьте права доступа к MongoDB

### Отладка
- Используйте консоль браузера для просмотра ошибок JavaScript
- Проверьте логи сервера для ошибок API
- Используйте endpoint `/health` для проверки состояния системы
